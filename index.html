Tentang Kami

Berangkat dari kebutuhan,
dibangun dengan kepercayaan.

Telur Jaya Abadi merupakan usaha penyedia telur dan kebutuhan pangan yang melayani pelanggan di wilayah Kediri dan sekitarnya.

Kami membuka jalur pemesanan yang sederhana: pelanggan memilih kebutuhan, mengisi data pengiriman, lalu meneruskan detail pesanan melalui WhatsApp untuk dikonfirmasi oleh admin.

Kelola Katalog

Panel ini menyimpan perubahan katalog pada LocalStorage browser. Ini bukan sistem autentikasi server.

PIN default dapat diubah di script.js. Untuk keamanan produksi, gunakan backend/CMS jika membutuhkan autentikasi sungguhan.
Pengelolaan gambar: pilih file JPG, PNG, atau WebP. Gambar disimpan di browser admin melalui LocalStorage. Untuk perubahan permanen bagi semua pengunjung, Anda juga dapat mengganti file di folder /images/ dan mengatur nama file melalui kode katalog jika diperlukan.
